# AGENTS.md

ValencyStudio - Spoofer — a Tauri 2 desktop app that drives a running Roblox Studio session
through a companion Luau plugin to replace assets across a place.

Three languages, three toolchains, one repo. Getting a change into the right one is most of the work.

## Commands

Bun is the package manager (`bun.lock`, Bun 1.3.14 in CI). Use `bun run ...`, not npm/pnpm.

| Command                | What it does                                                                                                                                                                                                                                                    |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bun run tauri:dev`    | Real dev loop. Runs `scripts/clear-dev-state.mjs` **first** — it kills `msedgewebview2` for this appId and deletes `%APPDATA%`/`%LOCALAPPDATA%`/com.valencystudio.spoofer (plus the audio temp dir). Local config, profiles and secrets are wiped every launch. |
| `bun run dev`          | Vite only, in a browser. No Rust backend, so every `invoke` fails. Use only for UI layout work.                                                                                                                                                                 |
| `bun run check`        | The gate. Required before pushing.                                                                                                                                                                                                                              |
| `bun run build:plugin` | Concatenates `plugin/` into `dist-plugin/ValencyStudioSpoofer.rbxmx`.                                                                                                                                                                                           |
| `bun run format`       | Prettier + `cargo fmt` + StyLua.                                                                                                                                                                                                                                |

`bun run check` expands to, in order: `format:check → build:plugin → typecheck → lint → test → build:app → rust:check → rust:lint → rust:test`.

Focused runs:

- One TS test file: `bunx vitest run src/utils/spooferStore.test.ts` (Vitest only collects `src/**/*.test.{ts,tsx}`).
- Rust: `bun run rust:test` / `rust:lint` / `rust:check` are all scoped to `--lib`. `src-tauri/src/main.rs` is a shim; the real crate is `app_lib` in `lib.rs`. Anything in `main.rs` is untested.
- E2E: `bunx playwright test`. **Not** part of `check` and **not** in CI. It boots `bun run tauri:dev` itself and attaches over CDP on port 9222, so it is slow and serial (`workers: 1`).

## What `check` does NOT cover

Run these separately when you touch the relevant code.

- **Selene** (Luau linter) — CI only: `cd plugin && selene .`. Installed via `aftman` (`aftman.toml` pins 0.31.0) or `cargo install selene --version 0.31.0`. Rules are relaxed in `plugin/selene.toml`.
- **`plugin/tests/run_tests.luau`** — not referenced by any package script or workflow. Run it manually; it is not a safety net.
- **Playwright e2e** — see above.

## Generated files (tracked in git — commit them)

- **`src/types/bindings.ts`** — written by tauri-specta. It is _not_ produced by any script; it is regenerated by the `#[cfg(debug_assertions)]` block at `src-tauri/src/lib.rs:111-128` on every **debug** app launch. After changing a command's name, arguments or return type, run `bun run tauri:dev` and commit the resulting diff. Do not hand-edit it, and do not let it drift.
- **`plugin/src/version/version.luau`** — overwritten from `package.json`'s `version` by `bun run build:plugin`. Bumping the version means running that script and committing the result.
- `plugin/.generated/` and `dist-plugin/` are gitignored output.

## Two-step registration traps

**New Tauri command** — it must be added to the `specta_commands!` macro in `src-tauri/src/lib.rs:10`. That single list is both the `invoke_handler` registration and the bindings export source. Add it there and nowhere else; `src-tauri/src/commands/mod.rs` is just `pub mod` declarations. From the frontend, call it through the generated `commands.*` object in `@/types/bindings` — do not hand-write `invoke('snake_case_string')`, or you lose the types and the rename safety.

**New or renamed Luau plugin function** — `plugin/plugin.luau` has no module system. It is textual `--#include` concatenation, so every file in `plugin/src/` shares one global scope and load order is load-bearing. `plugin/plugin.luau:28-34` asserts specific symbols exist. If you add a cross-file symbol, add it to `plugin/.luaurc` `globals` or Luau tooling and Selene will not see it.

## Invariants that are duplicated, not shared

- **Studio bridge port range `14285-14289`** is hardcoded in `src-tauri/src/studio_bridge/mod.rs:38-39` _and_ `plugin/src/config/runtime.luau:23-24`. Change both or the plugin silently never connects. `src/utils/pluginBridge.ts` has `DEFAULT_PLUGIN_PORT = '14285'` as a third copy.
- **Version** lives in `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json` and `src-tauri/tauri.dev.conf.json`. CI derives the release tag from `package.json` alone.
- `plugin/plugin.luau` and `plugin/tests/run_tests.luau` opt out of analysis with `--!nocheck` / `--!nolint`. Treat them as unlinted.

## Architecture worth knowing before you edit

- Frontend entry is `src/main.tsx` → `src/App.tsx`. Views are lazy-loaded and selected by a string tab id persisted in config, not by a router.
- `src/utils/{studioBridge,pluginBridge,apiClient}.ts` are the frontend's only paths into Rust and the plugin. New backend calls go through these rather than ad-hoc `invoke` in a component.
- Tests mock Tauri globally in `src/setupTests.ts` (`invoke` returns `null` except for a couple of commands). A new command that a test depends on may need a case added there.
- The desktop app runs an axum HTTP server; the plugin polls it. See `src-tauri/src/studio_bridge/` and `plugin/src/bridge/polling.luau`.

## Conventions

- **Imports must be sorted** — `simple-import-sort/imports` is an ESLint error. `bun run format` fixes it.
- `tsconfig.json` has `strict`, `noUnusedLocals`, `noUnusedParameters` on. `@typescript-eslint/no-explicit-any` is disabled, so `any` is an accepted escape hatch here.
- **StyLua, not Prettier, formats Luau** (`plugin/stylua.toml`: tabs, 100 cols, double quotes). Prettier's ignore list does not cover `plugin/`.
- **Clippy runs with `-D warnings`**, and `unwrap_used`, `todo`, and `missing_const_for_fn` are enabled in `src-tauri/Cargo.toml`. Do not silence them; fix or `#[allow]` with a reason.
- **i18n**: five locales in `src/utils/i18n/`. `DEFAULT_LANG` is `id` (Indonesian), **not** English — Indonesian is the fallback for any missing key, and a missing key silently renders as the raw dotted key path. New user-facing strings need an entry in all five files; a new language also needs `SUPPORTED_LANGS` and `locales` updated.
- `src/components/ui/*` is shadcn-generated (`components.json`). Match the existing pattern rather than hand-inventing variants.
- Husky runs `lint-staged` on commit: eslint+prettier for TS, `cargo fmt` for Rust, StyLua for Luau. Commits follow Conventional Commits; branch from `main` as `feat/`, `fix/`, `docs/`, `chore/`.

## Environment quirks

- Vite's dev watcher ignores `src-tauri/target/**` on purpose — cargo locks artifacts mid-write and chokidar dies with EBUSY. Don't "fix" that.
- `src-tauri/.cargo/config.toml` forces an 8 MB stack on all Windows targets; the Specta export spawns a dedicated 128 MB-stack thread to compensate. Do not remove either.
- `VITE_WEB_PREVIEW=true` aliases the Tauri API modules to `src/tauri-mock.ts` for browser preview. `src/utils/browserTauriMock.ts` does a similar runtime install.
- Vite dev proxies `/api` to `https://ispoofermotion.com` with `secure: false`.
- `.kilo/worktrees/` contains full copies of this repo from Agent Manager sessions. Exclude it from greps, globs, and any repo-wide search, or you will read the same files many times.
